# Reset Generator

A code generation utility that automatically generates `Reset()` methods for Go structs.

## Usage

Place the `// generate:reset` comment directly above a struct definition:

```go
// generate:reset
type UserSession struct {
    id        string
    authToken string
    data      map[string]interface{}
    metadata  []byte
    parent    *UserSession
}
```

Then run the generator from the project root:

```bash
go run ./cmd/reset/main.go
```

This will create a `reset.gen.go` file in the same package with the generated `Reset()` method.

## Reset Method Behavior

The generated `Reset()` method resets all fields to their zero values according to these rules:

### Primitive Types
- `int`, `int8`, ...`int64`, `uint`, `uint8`, ... `uint64` → `0`
- `float32`, `float64` → `0`
- `string` → `""`
- `bool` → `false`
- `byte`, `rune` → `0`

### Composite Types
- **Slices**: Truncated to zero length using `slice[:0]`
- **Maps**: Cleared using the builtin `clear()` function
- **Arrays**: Each element is reset (if the array type supports Reset, it's called)

### Pointer Types
- If the pointer is not `nil`, the value it points to is reset according to its type
- For pointers to primitives: `*ptr = zeroValue`
- For pointers to structs with `Reset()`: calls `Reset()`
- For other pointers: set to `nil`

### Nested Structs
- If a nested struct has a `Reset()` method, it will be called
- Checked at runtime using type assertion: `interface{ Reset() }`

### Nil Safety
- The generated method checks if the receiver is `nil` at the beginning and returns early

## Example

Given this struct:

```go
// generate:reset
type CacheEntry struct {
    key        string
    value      interface{}
    tags       []string
    metadata   map[string]string
    parent     *CacheEntry
    created    int64
}
```

The generated `Reset()` method will be:

```go
func (r *CacheEntry) Reset() {
	if r == nil {
		return
	}

	r.key = ""
	r.value = nil
	r.tags = r.tags[:0]
	if r.metadata != nil {
		clear(r.metadata)
	}
	if r.parent != nil {
		if resetter, ok := interface{}(r.parent).(interface{ Reset() }); ok {
			resetter.Reset()
		}
	}
	r.created = 0
}
```

## How It Works

1. **Scans**: Recursively walks through all `.go` files in the project (excluding tests, vendor, hidden dirs)
2. **Parses**: Uses Go's `ast` package to parse each file
3. **Finds**: Locates structs with `// generate:reset` comment
4. **Generates**: Creates `Reset()` methods following the rules above
5. **Writes**: Outputs to `packagename/reset.gen.go` in the same directory as the struct

## Generated File

The generated `reset.gen.go` file:
- Is marked with a code generation header: `// Code generated by cmd/reset - DO NOT EDIT.`
